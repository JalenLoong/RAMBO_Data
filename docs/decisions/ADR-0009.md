# Episode-isolated bounded collection and train-only normalization

## Decision and authorization
The user authorized the three-pilot then ten-demonstration roadmap with episode-level splits. Use explicit8/1/1 whole-episode assignments and train-only affine normalization. This prevents temporal-window leakage and validation/test influence on preprocessing. Dataset/task/core JSON schemas and the DATA-004 success definition are unchanged. Acceptance applies to this bounded data-preparation scope only.

## Consequences and evidence

Canonical collections keep an exact episode-UID map of source provenance/contact sidecars and explicit split assignment. Original single-export alias descriptions are retained as historical metadata, not used to select training rows. Videos and terminal images are copied byte-for-byte. WAM fits q01/q99 only on train actions, preserves constant/force dimensions, avoids clipping and resets VAE state per episode.

Three pilots and ten demonstrations passed real acquisition, data validation and frozen-model cache reload. Evidence: workspace `runs/audit/v2/DATA-005/20260916T055512Z/acceptance.json`. This proves the bounded data path; model learning/generalization remain untested.
