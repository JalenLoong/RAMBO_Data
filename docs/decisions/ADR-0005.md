# ADR-0005: Independent v2 numbering and restored governance

## Decision
The user accepted restoring the complete protocol, category counters starting at 001 independently of v1, and a shared v2 namespace across WAM/RAMBO. Current Work IDs migrate through the registry and aliases. Reword v2-only commit titles and publish the accepted pending work with exact remote leases.

## Consequences
Preserve original trees/author identities during rewording and all historical evidence paths and hashes. Current documentation migrates in a new commit; old history is not presented as if later decisions already existed. No main/v1 rewrite, data collection, runtime change or training. See [migration map](../governance/migration.json) and [execution plan](../work/archive/DOC-001/plan.md).
